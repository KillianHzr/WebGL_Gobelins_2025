# Célia

Expérience WebGL interactive réalisée dans le cadre de la formation aux Gobelins (2025).

## Le Projet
"Célia" est une immersion narrative visant à sensibiliser aux impacts environnementaux de l'IA et des datacenters. L'utilisateur suit une mission en pleine nature où il doit photographier un vison d'Europe, une espèce menacée, tout en découvrant les dessous écologiques du numérique.

## Stack Technique
- **Framework** : React + Vite
- **3D** : Three.js (React Three Fiber / Drei)
- **Animation** : GSAP + Theatre.js
- **Audio** : Howler.js
- **State Management** : Zustand

## Installation

```bash
# Installation des dépendances
npm install

# Lancement du serveur local
npm run dev

# Build pour la production
npm run build
```

## Fonctionnalités
- Système de narration dynamique
- Caméra contrôlée au scroll
- Interactions 3D (clic, drag)
- Gestion audio spatiale et ambiance
- Interfaces utilisateur intuitives
